# TerraClue

> **Follow the data. Find the trend.**

An educational MVP developed for the **Be An Earth System Trend Detective!** challenge at the 2026 NASA Space Apps Challenge.

TerraClue helps high school and college students explore environmental change without requiring advanced climate science knowledge. The application retrieves real monthly NASA POWER data for four Brazilian cities and three Earth science variables. It explains long-term trends, statistical confidence, and unusual observations in accessible language.

## Run locally

Serve the `dist` directory with any static HTTP server:

```powershell
python -m http.server 8000 --directory dist
```

Then open `http://localhost:8000`.

## Learning goals

The application introduces three concepts:

- **Trend:** a long-term direction and its estimated rate of change per decade.
- **Statistical significance:** whether the 95% confidence interval supports a clear trend direction.
- **Anomaly:** an observation that is unusual compared with the rest of the time series.

## NASA data

- NASA POWER Monthly API: https://power.larc.nasa.gov/docs/services/api/temporal/monthly/
- Period: 2001–2025
- Temperature and precipitation: products derived from MERRA-2
- Solar radiation: products derived from CERES

Data is retrieved directly in the browser. No scientific value is altered or generated by AI.

## Machine learning and statistics

1. The average seasonal cycle for each calendar month is removed.
2. Linear regression estimates the annual rate of change.
3. An approximate 95% confidence interval indicates whether the slope differs from zero.
4. An unsupervised Isolation Forest uses trend residuals and monthly changes to calculate anomaly scores.
5. The 5% highest-scoring observations are highlighted as unusual months.

The model is descriptive and educational. It does not forecast climate and does not replace expert-reviewed scientific analysis.
